# tigris_access_key (Resource)

Provides a Tigris access key resource.

~> **Note:** `secret_access_key` is only returned when the key is created. Reads and imports cannot recover it from the API.

## Example Usage

```terraform
# Create an access key with editor access to a specific bucket.
resource "tigris_access_key" "nas_upload" {
  name = "nas-upload"

  bucket_role {
    bucket = "landing-zone.example.com"
    role   = "Editor"
  }
}
```
